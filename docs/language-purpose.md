# Language purpose

SIBL は、軽量なインタプリタをアプリケーションへ組み込むための言語です。

## 目的

SIBL の主目的は、インタプリタごと配布しやすいユーザースクリプト環境を作ることです。

ホストアプリケーションは、スクリプトから利用できる関数や値を明示的に定義します。
SIBL スクリプトは、ホストが許可した機能だけを呼び出します。

## 想定用途

- アプリケーション内のユーザースクリプト
- ゲームやツールの軽量な拡張機能
- ホストアプリケーション専用の小さな自動化言語
- インタプリタ本体を同梱した配布
- JSON メッセージでホストとやり取りする実行環境

## 設計方針

SIBL は、大きな標準ライブラリを持つ汎用言語ではなく、ホストアプリケーションに埋め込まれる小さな言語を目指します。

そのため、言語本体はできるだけ小さく保ちます。
ファイル操作、ネットワーク、UI、音声、ゲームオブジェクト操作などは、標準機能として持つのではなく、ホスト関数として提供します。

## ホスト中心の設計

SIBL の実行環境は、次の3つで構成されます。

```text
Host application
  + SIBL interpreter
  + SIBL script
```

ホストアプリケーションは、利用可能な関数を `embedded-Settings.json` で定義します。
インタプリタはその定義をもとに、スクリプトからの関数呼び出しを JSON メッセージとしてホストへ渡します。

## 安全性

SIBL は、標準では危険な操作を持たない設計を目指します。
スクリプトが何をできるかは、ホストが公開した関数によって決まります。

必要に応じて、実行環境は次の制限を持てます。

- 最大実行ステップ数
- 最大再帰深度
- 最大メモリ使用量
- 使用可能なホスト関数
- 使用可能な権限

## 配布

SIBL は、開発時には外部の `embedded-Settings.json` を読み込めます。
配布時には embedded lock により、設定をインタプリタ内へ取り込み、外部設定による上書きを禁止できます。
